## 模型与对照

采用原DPA-P2PNet的ViT Adapter、多尺度提案和匈牙利点匹配，不改核心网络。对照共享同一初始化、病例划分和最大8轮预算。

1. 原80轮验证最优模型：在新划分和统一ROI口径下重新评估，在验证集选择后处理阈值。
2. 数据扩充对照：ROI内普通交叉熵及均匀crop采样。
3. 召回与系膜优化：Focal分类损失gamma=1.5、系膜权重1.5、背景权重0.25、每个真值点最多4个困难背景查询且至少128个、病例均衡并轻度加权系膜样本。

微调初始学习率2e-5，后期编码层使用0.1倍率；梯度累积4次，batch size 1。前2轮仅训练检测头，之后解冻特征金字塔及ViT末2层。梯度检查点和BF16降低显存，单进程显存上限约6.36GB，实际峰值分配约4.15GB。

预定选模指标为0.4×检测F1+0.4×系膜F1+0.2×三类宏F1，基于验证集。后处理仅用验证集在前景/背景概率比0.6/0.8/1.0/1.2、去重距离4/6/8/10中选择，并要求检测精确率至少0.55。固定10像素点匹配距离，所有类别使用一对一最大匹配。

数据对照在4轮后早停，未优于原始初始化，因此保留原模型。优化模型在第1轮达到最佳，后续4轮没有改善而早停。保留未微调初始化作为选模候选，避免将退化检查点替换原模型。首轮收益来自检测头微调、损失和采样的组合，不能据此宣称ViT末层微调带来收益；各项单独消融尚未完成。

总体检测和系膜F1提升，但新增病例中的系膜类别出现过检：召回率提高，精确率、F1和计数准确性下降。当前适合继续研究召回与分类的平衡，不能声称对新增病例的系膜识别已全面改善，也不应直接接入定量计数/评分替换旧模块。

测试病例仅7例，另输出按病例配对bootstrap置信区间。测试结果已查看，这一批应视为本轮固定回顾性对照；后续反复优化不能继续把它称作全新盲测集。

2,000次病例配对bootstrap得到：检测F1增量0.0564，95%区间[0.0078,0.1051]；召回率增量0.1641，区间[0.1255,0.2065]；系膜F1增量0.1109，区间[-0.0393,0.2520]，跨过0。三类宏F1增量区间同样跨0，不能据此宣称类别识别提升已稳定。

歧义标注排除后，用已选权重及原先固定的1.2/10后处理复核验证集：检测F1 0.6436，召回率0.6732，系膜F1 0.5038，宏F1 0.4452。未更换权重或按测试表现重新调参；这一步属于选定模型的数据质控复核，不是完整重放全部历史轮次选模。
