# 紫癜性肾炎数字病理项目：进展与下一阶段讨论材料

会议日期：2026年11月5日。整理日期：2026年11月4日。

本材料基于已保存的代码、实验记录与医生反馈。最新细胞优化实验日期为2026年10月28日；以下计划尚未实施，不能作为新增实验结果汇报。

## 一、建议开场汇报

目前已经完成两部分工作。第一部分是病变分析与分型报告：完成肾小球分割、新月体定位和三亚型分类、系膜及毛细血管内增生判断、肾小管萎缩分析，并形成逐肾小球统计和分别输出的ISKDC、Oxford报告；已有95例病例分型对照结果。第二部分是固有细胞检测：完成内皮、系膜、足细胞三类点检测及计数，最新优化后整体检测F1为0.771，三类宏平均F1为0.618，并已有真实图像的逐点核对证据。下一阶段重点提高足细胞检出能力，同时研究把系膜和内皮相关定量证据用于辅助M/E判断。当前最需要确认的是局部计数单位、病理阳性标准及困难细胞的标注方法。

### 3. 固有细胞检测与计数

方法：DPA-P2PNet提供候选细胞点；在43例升级模型上，进一步冻结检测器，加入双视野ResNet18，联合64×64局部图像、192×192上下文图像、原模型概率及相对位置，识别内皮、系膜、足细胞与背景。训练采用难负样本、类别平衡及验证集参数选择，新增分类模块训练10轮。

## 三、医生已反馈的标准及仍需澄清的边界

以下为本次用户转述的医生反馈，作为待会议确认的项目口径记录，不直接改写为已经实现的算法规则。

| 内容 | 医生反馈 | 转成算法前还需要明确 |
|---|---|---|
| 系膜增生 | 系膜区≥3个细胞；Oxford标准≥4个，受切片厚度影响 | 一个系膜区如何画边界、统计哪些细胞核、染色和厚度、一般病变标准与Oxford标签分别如何保存 |
| 系膜增生程度 | 轻度3–4、中度5–6、重度7–8，能分级更好 | ≥9个如何处理；一个小球有多个系膜区时按最重区、平均程度还是受累比例分级 |
| 毛细血管内增生 | 毛细血管袢内正常0–1个内皮细胞，>1个算增生 | “一个袢”具体指哪个二维轮廓；腔壁与腔内细胞如何计数；是否还须结合管腔狭窄/闭塞 |
| 混合细胞 | 袢内可能有淋巴细胞、单核细胞，缺少免疫组化难判 | 常规染色能否给确定/不确定标签；哪些困难样本需要特殊染色辅助，而非强制归入内皮 |

公开参考用于提示需统一之处：日本肾脏学会指南所列Oxford参考表，系膜细胞分档为<4、4–5、6–7、≥8；E定义包含毛细血管腔内细胞增多并导致管腔变窄。医生给出的轻/中/重计数不应直接与该表的0–3分档混为一套标签，应请科室指定项目采用的版本。该参考主要来自IgA肾病，应用于本项目紫癜性肾炎时，仍由科室确认研究报告口径。[日本肾脏学会指南，表2，第52页](https://jsn.or.jp/en/guideline/pdf/IgA_eng.pdf)

另需确认M病例级汇总。当前代码按“预测M阳性肾小球比例≥50%”给M1；上述参考的简化表述为超过半数肾小球受累，严格计分还涉及系膜评分。会议需明确采用局部计分汇总还是阳性小球比例，并确认恰好50%的归属及计数分母。既往95例保留原版本结果；确认后另出新版对照，不静默覆盖基线。

## 四、下一步工作建议

### 任务A：重点提升足细胞检出

目标：优先提高足细胞召回，同时约束误检和计数误差，不通过单纯放宽阈值制造召回提升。

1. 用现有误检/漏检图复核足细胞定义及标注完整性，区分原检测器未提出候选点、候选点被分类器丢弃、被误分成内皮/系膜三种情况。
2. 按原因优化：候选漏检加强足细胞及困难区域训练；类别混淆加强针对性正负样本与上下文分类；阈值和去重问题只在验证集调整。检查10像素去重是否抑制相邻真实细胞。
3. 建议先共同核对20–30个肾小球的足细胞典型与困难实例，覆盖正常外观、病变背景及低质量图像；数量是拟议工作量，需会议确认。
4. 固定新病例级测试集，报告足细胞精确率、召回率、F1、逐小球计数误差，附三类混淆和完整切片证据图。当前足细胞召回0.644、F1 0.614作为基线，提升目标及误检容忍度会上共同确定，不承诺未经验证的数值。

足细胞定位和计数是本任务输出；是否进一步研究足细胞损伤、脱落或密度变化，需要额外定义终点。单张二维切面的核计数不能直接等同整个肾小球的三维足细胞总数。

### 任务B：系膜定量证据辅助M

拟议流程：识别系膜区 → 将系膜细胞点归入各区 → 按确认规则计算局部计数/分级 → 汇总单肾小球病变 → 与既有M分类器共同判别 → 形成病例级M及可核对证据。

新增工作是“局部解剖区域与细胞归属”，现有模型只有肾小球ROI和细胞点，尚无经过标注验证的系膜区分割。不能把整小球的系膜细胞总数直接与3或4比较，也不能用任意固定距离聚类替代病理上的系膜区而不验证。

建议保留局部实测数量，再分别生成科室轻/中/重分级和Oxford需要的病变标签，避免两套阈值混用。首版对系膜区边界不清或细胞身份不确定的区域保留“不确定”状态。

### 任务C：毛细血管袢及腔内形态证据辅助E

拟议流程：辨认毛细血管袢/腔的二维轮廓 → 记录内皮及其他腔内细胞证据 → 综合局部计数和管腔形态 → 与现有E分类器联合判断 → 输出可见异常区域、计数和病例级E。

目前细胞模型只有内皮、系膜、足细胞三类，尚不识别淋巴/单核细胞，也未形成经过验证的毛细血管腔分析模块。医生的“>1个”必须先明确计数单位和适用条件。首版可使用医生直接标注的E阳性/阴性局部，学习局部形态并利用细胞数量作辅助证据，不必预先承诺所有免疫细胞都能在常规染色上细分。

免疫组化或配对染色作为困难病例确认方案，由科室判断是否已有材料、能否对应到同一病变及是否有必要。不能把身份不确定的腔内细胞全部计作内皮细胞。

### 任务D：验证细胞证据是否真正改善分型

采用相同病例、固定标注和预先锁定参数，比较三种方式：现有图像M/E分类；局部结构与细胞定量；图像分类与定量证据联合。先验证局部/小球判断，再验证病例级结果。

报告各类敏感度、特异度、F1、平衡准确率、Kappa及病例级置信区间，同时显示“现有模型错、联合后对”及“联合后新增错误”的病例。轻/中/重分级增加混淆矩阵和加权Kappa。参数只在训练/验证数据选择，新测试集不参与调阈值；已有95例作为历史基线和错误分析来源，不能在反复针对其优化后称其为新独立验证。

## 五、明天建议优先问清的8个问题

1. **足细胞目标及难例**：这次要优先增加检出数量、提高类别准确度，还是为后续足细胞密度/损伤评价服务？典型足细胞和容易混淆的细胞能否在现有核对图上现场指出？是否仅标肾小球脏层足细胞，壁层上皮及新月体相关细胞如何处理？
2. **局部区域定义**：能否现场各画几个正常及异常系膜区、毛细血管袢/管腔的边界，并指出计数包括哪些核、哪些不包括？这是将点检测变成病理计数最关键的新增标注。
3. **系膜两套口径及汇总**：科室3/4细胞阳性阈值、3–4/5–6/7–8轻中重与Oxford参考表如何分别使用？≥9个如何分；多个系膜区、多个小球如何汇总；恰好50%病例如何归属？
4. **E的完整阳性依据**：袢内>1个内皮细胞是否可独立判阳，还是同时要求管腔变窄/闭塞？只有腔内免疫细胞增加、或内皮身份不清时，E怎样标注？请各给一个支持及反例。
5. **制片与染色**：现有数据的切片厚度、主要染色和扫描倍率是否一致？哪个染色作为M/E计数主依据？不同染色/连续切片是辅助核对还是共同计分，同一小球如何避免重复统计？
6. **标注完整性与不确定项**：圈出的肾小球内是否全部目标细胞已标完？未圈区域不能直接作阴性；模糊核、重叠核、身份不能确定的细胞是否允许单独标“难判”？既有43例标注是否按同一规范？
7. **病例级真值与分母**：95例报告基于哪些切片/染色/层面？模型是否拿到了相同范围？全球硬化、不完整及质量差的小球是否纳入M/E分母，存在多个切片时怎样去重？
8. **标注合作与验收**：能否指定一位主要复核者并对困难病例共同复核？先进行20–30个肾小球的小规模规范试标，再决定正式数量。建议覆盖正常、增生边界、不同程度、E阳性与混合细胞难例，并另外预留不参与开发的新病例作最终验证。
